1. Service Description & Educational Scope

CloudDesk is an educational technology (EdTech) SaaS platform providing browser-accessible virtual computer science practice environments. The service allows university students, programming learners, and researchers to practice software engineering, run code compilers (e.g. GCC, Python, Flutter, Rust, Node.js), and complete computational assignments without hardware constraints.

2. Prohibition of Cloud Storage and File Hosting Services

CloudDesk is strictly an interactive educational runtime environment and is NOT a cloud storage, file sharing, cyberlocker, or backup service.

  • Users are strictly prohibited from using the platform for storing media files, backups, warez, pirated content, or distributing personal files.
  • The virtual lab environment includes only an ephemeral workspace scratchpad intended solely for holding project source code during active practice sessions.
  • CloudDesk does not offer permanent file storage plans, public download URLs, or data locker utilities.

3. Educational Hourly Practice Passes

Users purchase interactive coding lab practice time in hourly blocks (e.g., 1-Hour Sprint Pass, 2-Hour Assignment Pass, 3-Hour Project Pass). Lab time is metered strictly while the interactive learning session is running and pauses when stopped.

4. Acceptable Academic Use Policy

Users agree to utilize the virtual programming lab in accordance with academic integrity and ethical computing standards. The following activities are strictly prohibited and result in immediate termination without refund:

  • Cryptocurrency mining or unauthorized distributed computing.
  • Network scanning, penetration testing against third parties, or launching DoS/DDoS attacks.
  • Hosting public web servers, illegal proxies, botnets, or distributing malware.
  • Hosting or distributing copyrighted intellectual property or pirated media.

5. Payment Processing & Fees

All transactions for educational lab passes are billed in Indian Rupees (INR) and processed securely through licensed payment gateway partners (including Razorpay). Passes are credited to the student's learning profile instantly upon successful transaction verification.

6. Account Security & Contact

Users are responsible for safeguarding their login credentials. For assistance, queries, or educational institution licensing, contact our support team at support@clouddesk.local or through our Contact Page.
